# 数据库设计基础

当前使用 H2 文件数据库；测试使用独立内存数据库，不读取真实记录。

Flyway 的 `V1__create_student_profiles.sql` 仅提供基础表 `student_profiles`：UUID 主键、唯一学生编码 `student_code`、展示名 `display_name`。不存在初始学生数据或演示账号。

Hibernate `ddl-auto=validate` 校验实体与迁移一致，禁止用自动重建表代替迁移。数据库运行文件在 `backend/runtime`，不加入 Git。

B 汇总完整 ER 图、数据字典、来源标识和迁移顺序；A、C、D 负责各自业务表定义。新增表和字段使用新的版本化迁移；已有迁移一旦共享执行就不修改。
