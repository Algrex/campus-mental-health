## 修复内容

### Jackson 3 弃用方法

`DemoWorkflowIntegrationTest.java` 的 **18 处** `.asText()` 改为 `.asString()`。项目使用 `tools.jackson.databind.JsonNode`，Jackson 3 已将前者作为弃用别名，推荐后者；参见 [Jackson JsonNode API](https://javadoc.io/static/tools.jackson.core/jackson-databind/3.0.4/tools.jackson.databind/tools/jackson/databind/JsonNode.html#asText())。

`get("csrfToken")` 返回 JsonNode，仍需转换为字符串才能赋给 `String csrf`；所以不能直接删除转换方法。`toString()` 产生 JSON 表示，也不应替代原始令牌字符串。保留现有断言和登录行为，开启弃用提示的干净编译通过，未出现该方法的弃用警告。

### 初始抽屉加载

个案抽屉原先只监听后续编号变化：组件首次带编号挂载时不请求数据，导致带 `?case=...` 的预警链接可能出现空内容。`CaseDrawer` 与同模式的 `StudentDrawer` 改为首次立即执行监听。组件回归测试和真实个案深链接检查通过。

### 测试与产物管理

补充规则边界、CRUD/CSV、角色矩阵、生命周期、真实分区不重叠、错误重试和表单交互测试；在 jsdom 中模拟 `window.scrollTo`，消除测试环境不支持滚动产生的噪声。启动脚本生成的 Python 字节码加入 Git 忽略，无需新增全局工具或测试依赖。
