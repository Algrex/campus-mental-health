# 测试与验证

检查入口为仓库根目录的 `scripts/check.ps1`；CI 分别检查 Java 后端和前端。

现有后端集成测试覆盖真实启动、健康与工程信息、匿名业务访问拒绝、Flyway/JPA 持久化。前端测试覆盖请求错误和取消信号。

初始化与工作区生成需要验证不同克隆目录、空格路径、缺少本地缓存、工具版本和外部工作区输出；个人路径不能成为共享构建的前提。

后续业务测试应覆盖档案越权、导入错误与幂等、计分、时序缺失与泄漏、通知重试、干预状态流转和页面失败反馈。每个模块负责人提供自己的测试，跨模块变化补齐流程回归。

测试记录写明输入、预期、实际结果与执行环境。工程骨架检查通过不代表完整业务验收通过；远程 CI 以实际 GitHub 运行结果为准。
