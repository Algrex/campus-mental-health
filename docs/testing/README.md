# 检查与验证

入口 `pwsh -NoProfile -File scripts/check.ps1`，在集中完成代码修改后运行。后端用独立内存库与固定合成测试夹具，CI 不下载外部大数据或写入本机业务数据库。

覆盖范围：

- 真实 Spring Boot 启动、Flyway/JPA 持久化、健康与 Demo 元数据。
- 真实 Cookie/CSRF 登录、未授权写拒绝、跨学院/跨学生访问拒绝、联系人通知隔离。
- PHQ 计分边界、第 9 项优先信号、近 7 天打卡规则，以及测评级别与综合规则级别的区分。
- 测评幂等、当天打卡更新、备注编辑去重、整数类型和睡眠精度、活动预警去重及新信号提醒；并发提交下的记录与个案一致性。
- 受理、干预、干预后新自评、复评、关闭与记录保留；非法状态流转拒绝、待复评新信号退回受理和首次受理人保留。
- 随访当前计划与历史隔离；通知收件人权限、学生迁学院后的旧通知权限及联系人摘要隔离。
- V2 合法历史库升级 V3：记录保留、随访状态回填、排序序号、规则等级兼容回填与新增数据库约束；异常重复活动个案须升级前人工处理。
- CSV 部分成功与重复学号错误。
- Weka 特征排除、缺失处理、确定性评估、模型文件产出和概率推理；大数据模式按实际运行的评估 JSON 记录。
- 前端请求错误、取消、CSRF 传递、完整自评交互、自评提交页及个人档案的综合规则级别展示、新打卡提高当前关注时的支持提示与随访历史过滤；ESLint、Prettier、生产构建。

前端与数据库错误不会返回伪造成功。自动化测试不代表已验证真实通知供应商、临床表现或公网生产部署。

环境可移植性已有历史基础验证；本次只集中检查新增功能，不重复创建干净克隆与安装全套工具。运行结果与边界记录在 [verification.md](verification.md)，GitHub CI 以实际远程运行记录为准。
