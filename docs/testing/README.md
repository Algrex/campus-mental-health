# 测试与验收

骨架已有后端集成测试：真实启动服务、健康与工程信息、匿名业务访问拒绝、Flyway 与 JPA 持久化。前端已有请求错误和取消信号测试。

全员负责本模块测试；F 汇总完整流程回归。后续应添加档案越权、错误/重复导入、量表计分、时序缺失与泄漏、通知幂等/重试、状态流转、前端失败反馈等用例。

检查入口是根目录 `scripts/check.ps1`；CI 分别验证后端和前端。CI 使用 JDK 21 与 Node 24，项目本地便携工具不上传仓库。

测试报告记录需求编号、输入、预期、实际结果、日期和执行证据。真实功能完成情况以根目录需求清单为准，骨架测试通过不代表完整课题验收通过。
